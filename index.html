自我覺察

畫出你的情緒

情緒理解：學習用圖像與詞語，認出並說出自己的情緒。

文字版步驟
  1. 用形狀工具畫出一張簡單的臉（可試用填色工具）。
  2. 用螢光筆上色，選擇能代表你心情的顏色。
  3. 寫下一個情緒詞，並可調整表達符號的顏色或大小。
  4. 用套索工具選取並加入你的元素收藏區。

引導建議：結合形狀、顏色與語詞，幫助學生建立情緒詞彙並加強自我表達。

自我覺察

情緒分類遊戲

情緒認識：辨識與分類不同類型的情緒。

文字版步驟
  1. 用線條將頁面分成兩欄，分別標示「正向情緒」與「負面情緒」。
  2. 使用貼圖或相機拍攝 4 種不同的臉部表情。
  3. 用套索工具將表情圖拖曳到對應的欄位中。
  4. 為每一欄加上一個情緒詞（如：快樂、生氣、緊張……）。

引導建議：幫助學生更清楚辨識自身與他人的情緒反應，增進情緒詞彙與理解力。

隱私提醒：拍攝表情時，建議用貼圖或不露臉的方式，避免拍到同學的臉。

自我覺察

我的注意力溫度計

練習觀察自己的注意力狀態與影響因素。

文字版步驟
  1. 開啟老師提供的「注意力溫度計」模板頁。
  2. 用螢光筆標記今天的注意力等級（1–5 分）。
  3. 用文字或畫筆寫下影響你專注的原因。
  4. 若你願意，可將這張圖分享給你信任的人。

引導建議：引導學生反思專注狀態，有助於建立正向的學習自我認識。

自我管理

我的平靜泡泡

用顏色與圖形製作專屬的靜心圖卡。

文字版步驟
  1. 用筆畫出一個讓你感到平靜或放鬆的圖形。
  2. 用螢光筆填上讓你感覺舒服的顏色。
  3. 在圖形裡加入讓你冷靜或放鬆的詞語。
  4. 用套索工具選取整個圖形與文字，一起存入你的元素收藏。

引導建議：透過色彩與圖像幫助學生學會自我安撫與情緒管理。

自我管理

我的正向聲音

自我鼓勵：練習說出支持自己的話語，提升信心。

文字版步驟
  1. 寫下 3 句你希望別人對你說的鼓勵話語。
  2. 改寫成「我對自己說」的版本，例如：「你很努力」→「我很努力」。
  3. 加入貼圖做視覺設計。
  4. 使用 Clips 製作成鼓勵短片，可以加入文字、音樂，成為你專屬的正向語音卡。

引導建議：讓學生用創意影片呈現自己的鼓勵語，有助於內化正向語言並強化自我認同。

自我管理

願望星星罐

希望與目標：想像並可視化實現小目標的希望與動機。

文字版步驟
  1. 畫出一個罐子或使用老師提供的模板。
  2. 在罐中畫 3 顆星星，分別在每顆寫下一個願望。
  3. 用套索工具改變顏色或位置，表示你想專注實現的那一個願望。
  4. 匯出並儲存這頁內容（如存入相簿、學習檔案或目標筆記中）。

引導建議：讓學生以具象圖像展現願望，有助於激發主動實踐的動力。

社會覺察

好朋友小清單

明確觀察與記錄友善行為。

文字版步驟
  1. 建立一張好朋友行動清單，可以是你做過的，也可以是你想嘗試的行為。
  2. 開啟 Split View 搜尋相關圖片並拖曳到頁面中。
  3. 每項行動搭配一個 emoji，表示別人的感受。
  4. 勾選你這週完成的行動。

引導建議：引導學生觀察與練習友善行動，並透過簡單回顧建立正向社交習慣。

社會覺察

發現的善意

看見他人的善意並練習感受表達。

文字版步驟
  1. 用動作來表演並拍照這週別人對你表現善意的情境。
  2. 將照片插入 Goodnotes 頁面中。
  3. 用文字框或語音轉文字寫下你的感受。
  4. 用星號或螢光筆標記你覺得最溫暖的一刻。

引導建議：結合行動與圖像，引導學生觀察他人善意並學習感恩表達。

隱私提醒：拍照前先徵得同學同意，或用背影、手部動作呈現。

人際技巧

拆封你的正能量

建立同儕信任與正向互動。

文字版步驟
  1. 選一位同學，想一段你真心想給他的正向回饋或稱讚。
  2. 使用文字方塊寫下一句友善的話。
  3. 用膠帶工具把這段話蓋起來。
  4. 和同學交換 iPad 或頁面，互相打開膠帶閱讀「友情膠帶：給你的驚喜」。
  5. 完成後，全班一起討論：讀到這句話，你有什麼感覺？

引導建議：讓學生練習給予正面肯定與建立信任感。善用膠帶工具的互動性，有助於學生感受到「言語的力量」，也培養正向回饋的習慣。

負責任的決策

今天做了好事嗎？

鼓勵學生主動行善，覺察行為對他人的影響。

文字版步驟
  1. 搜尋 3–5 個這週你想嘗試的善意行動（例如：主動打招呼、幫同學收桌子）。
  2. 用螢幕分屏找圖片或貼圖，放在頁面中央。
  3. 每完成一項，就用套索工具把圖片移到圓圈中。
  4. 在圖片旁寫下一個詞，描述這個行動帶來的感受。

引導建議：這個活動透過視覺化記錄，幫助學生將「善意」具體化、日常化。搭配反思詞彙練習，有助於建立情緒詞彙庫與正向人際互動。

負責任的決策

玻璃珠日記

記錄那些一點一滴累積信任的貼心行動。

文字版步驟
  1. 使用「玻璃珠日記」模板（含圓點或罐子圖示）。
  2. 每做一件善意或誠實的事，就加入一顆貼圖或畫出一顆玻璃珠。
  3. 在便利貼中寫下你做了什麼、或當下的感受。
  4. 一週後，回顧你的玻璃珠日記，思考這些行動對你或他人的影響。

引導建議：這個活動幫助學生以視覺化方式追蹤自己的正向行為，理解「信任是慢慢累積的」。同時也提升情緒識讀與內在動機。
